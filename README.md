## Лабораторная работа №3: Работа с коллекциями
В ходе работы была изучена концепция хранения и обработки данных. Основное внимание уделено **спискам, кортежам, множествам и словарям**. 
Были исследованы свойства данных контейнеров и базовые операции над ними. Для закрепления материала и проверки теоретических знаний были проведены небольшие практические эксперименты, демонстрирующие поведение коллекций в различных условиях.

## Лабораторная работа №4: Обработка данных и оптимизация
Целью данной работы было освоение методов вариативной обработки информации. В ходе выполнения заданий:
1.  Изучены и применены на практике несколько способов решения типовых задач.
2.  Проведено измерение времени работы эквивалентных решений для оценки их производительности.
3.  Сделан акцент на важность **читаемости кода (Readability)**. По итогам анализа выбраны оптимальные варианты: не самые короткие по количеству символов, но наиболее понятные и легкие для восприятия человеком.
